# hammerspoon-config

Hammerspoon configuration that automatically switches the input source to English when Raycast is opened.

## Features

- Automatically switches to English when Raycast window appears
- Restores the previous input source (Korean/English) when Raycast is closed
- You can still freely toggle between Korean and English inside Raycast

## Requirements

- [Hammerspoon](https://www.hammerspoon.org)
- [Raycast](https://www.raycast.com)
- macOS

## Installation

1. Install Hammerspoon
2. Copy `init.lua` to `~/.hammerspoon/init.lua`
3. Grant Hammerspoon accessibility permission in **System Settings → Privacy & Security → Accessibility**
4. Click **Reload Config** in the Hammerspoon menu bar icon
